# To-Do List – Menedżer zadań

## Opis projektu
To-Do List to prosta aplikacja internetowa
do zarządzania codziennymi zadaniami.

## Funkcjonalności
- Dodawanie nowych zadań
- Oznaczanie zadań jako wykonane
- Usuwanie zadań
- Zapisywanie zadań w przeglądarce

## Technologie
- HTML5
- CSS3
- JavaScript
- Git i GitHub
- Trello

## Uruchomienie
1. Pobierz repozytorium z GitHub.
2. Otwórz folder projektu.
3. Uruchom plik index.html w przeglądarce.
